# Dashboard Module Guide (仪表盘模块指南)

本文档分为两部分：
1.  **现有功能拆解**：详细列出当前 Dashboard 包含的所有特性。
2.  **从零构建提示词**：如果您需要从头开发一个一模一样的 Dashboard，应该如何向 AI 提问。

---

## 📅 Part 1: 现有功能详细拆解 (Current Features)

### 1. 核心指标卡片 (KPI Cards)
位于页面顶部，展示最关键的财务与销售健康度。
*   **Total Cash In (现金总流入)**：
    *   显示实际到账的资金总额。
    *   UI: 绿色数字，配以前月增长率说明。
*   **Ready to Invoice (待开票)**：
    *   显示已完成交付但尚未开票的里程碑金额。
    *   UI: 琥珀色警告样式，提示需立即行动。
*   **Pipeline Value (商机储备)**：
    *   显示所有活跃商机的预计总金额。
    *   显示活跃商机数量 (Active Deals Count)。

### 2. 核心图表
*   **Customer Map (客户地图)**：
    *   可视化展示客户的地理分布（中国地图）。
    *   支持缩放交互。

### 3. 项目与交付列表
*   **Active Projects (活跃项目)**：
    *   表格视图。
    *   字段：客户名、项目名（可点击跳转）、预计金额、当前状态（Badge）。
    *   限制显示：前 5 条或其他高优先级项目。
*   **Milestone Watch (里程碑监控)**：
    *   列表视图。
    *   展示近期需要关注的收款里程碑（如：项目启动款、阶段验收款）。
    *   字段：里程碑名称、客户、金额、对应日期。

### 4. 投标/采购看板 (Active Procurements)
*   **网格视图 (Grid View)**：
    *   展示正在进行中的投标项目。
    *   **状态标签**：区分草稿、准备中、已提交、进行中、中标/未中标。
    *   **关键信息**：投标编号、客户名、采购方式（单一来源/公开招标等）、截止日期（Deadline）。
    *   **交互**：点击卡片直接跳转到对应的商机详情页。

## 🚀 Part 2: 从零构建提示词 (Zero-to-Hero Prompt)

如果您现在面对一个空白的项目，想要让 AI 一次性生成上述 Dashboard，请使用以下提示词。

### 📋 Master Prompt (复制给 AI)

> **角色设定**：
> 你是一个精通 Next.js 14、Tailwind CSS 和数据可视化的中后台全栈专家。
>
> **任务目标**：
> 请为 Lead-to-Cash (ERP) 系统开发一个现代化的首页 Dashboard (`/page.tsx`)。目标用户是公司高管和销售总监，需要一目了然地看到财务状况和业务进展。
>
> **技术栈要求**：
> *   **框架**: Next.js (App Router)
> *   **UI 组件**: Shadcn UI (Card, Table, Badge, Button, Progress)
> *   **图标**: Lucide React
> *   **国际化**: 使用 `useI18n` hook。
>
> **功能模块详细要求**：
>
> 1.  **KPI 概览区 (`KPI Cards`)**：
>     *   请创建一排 3 个卡片。
>     *   **Card 1 [Cash In]**: 显示总回款金额（绿色，强调健康）。数据源：`/dashboard/stats`。
>     *   **Card 2 [Ready to Invoice]**: 显示已达成但未开票的里程碑金额（琥珀色/橙色，强调需处理）。这是最重要的待办事项。
>     *   **Card 3 [Pipeline]**: 显示所有活跃商机的预计总价值及商机数量。
>
> 2.  **客户分布地图 (`Customer Map`)**：
>     *   在页面左侧或上方占据较大区域。
>     *   封装一个 `CustomerMap` 组件，使用 `echarts` 或 `react-simple-maps` 绘制中国地图，展示客户分布。
>
> 3.  **活跃项目列表 (`Active Projects`)**：
>     *   使用 `Table` 组件。
>     *   列头：客户、项目名（Link 跳转详情）、金额、状态。
>     *   若无数据，显示 Empty State 占位图。
>
> 4.  **近期收款里程碑 (`Milestones`)**：
>     *   设计一个卡片列表，列出即将到期的 3-5 个收款节点。
>     *   每个节点显示：款项名称（如“首付款”）、客户名、金额、日期。
>
> 5.  **正在投标项目 (`Active Procurements`)**：
>     *   展示为一个 Grid (网格) 布局的卡片组。
>     *   每个卡片代表一个投标中的商机。
>     *   显示：投标编号、截止日期（如果快到了用红色高亮）、采购类型（单一来源/公开招标）、当前状态徽章。
>
> **数据交互**：
> *   所有数据请通过 `api.get()` 异步获取。
> *   不需要 Mock 数据，请写出真实的 `useEffect` 数据获取逻辑。
> *   金额均需使用 `Intl.NumberFormat` 格式化为人民币 (CNY) 或美元。
>
> **布局结构**：
> *   使用 Grid 布局 (`grid-cols-12`)。
> *   KPI 占满一行。
> *   Map 占 7/12，Project List 占 5/12。
> *   Procurements 占满底部一行。
